## PIE

**PIE790 (62)** — 본문이 실제 문장을 갖게 된 뒤 남은 `pass`. 대부분 테스트.
자동수정.

**PIE810 (2)** — `line.startswith('"') or line.startswith("'")` (NTS/X1Y1 리더).
ruff가 unsafe로 표시하는 이유는 일반적으로 인자에 부수효과가 있을 수 있어서인데,
여기선 리터럴이라 튜플로 접는 것이 동작 동일. 직접 수정.

## RET

대부분 `return` 뒤의 `else` 제거(RET505)로, dedent가 발생한다 — `MdModel.py`의
수치 코드 포함. 변환은 if 분기가 이미 반환하는 경우에만 적용되므로 안전하다.

### RET503 2건 — 자동수정 대상이 아니라 실제 비대칭이었다

**`MdModel.load_file_info`**: 디렉터리면 `file_info`를 조기 반환하고, 파일이면
끝에서 떨어져 `None`을 돌려주고 있었다. **같은 함수가 경로에 따라 dict 또는 None을
반환**하는 상태. 호출부 3곳(`MdModel.py:959`, `1212`, `MdUtils.py:930`)이 모두
반환값을 쓰지 않아 드러나지 않았다. 양쪽 다 `file_info`를 반환하도록 맞췄다.

**`table_view.headerData`**: 역할에 해당하지 않으면 암묵적 `None`. Qt가 기대하는
동작이므로 `return None` 을 명시했다.

### RET504는 규칙째로 무시

16곳 중 9곳이 앱 코드이고 거의 전부 수치 루틴이다:

```python
rot_mx = np.dot(v, w)
# print("rotation_matrix:",rot_mx)   ← 바로 이 변수를 찍는 주석
return rot_mx
```

```python
normal = normal / np.linalg.norm(normal)
return normal
```

여기서 **변수 이름이 "무엇을 반환하는지" 설명하는 역할**을 하고, 바인딩을 남겨두는
것이 값을 들여다볼 수 있게 한다(위 주석 처리된 print가 그 증거다). 인라인하면 한 줄
줄이는 대신 설명을 잃는다. S110/S112/S311을 근거와 함께 무시한 것과 같은 판단이며,
이유를 `pyproject.toml` 에 적었다.
